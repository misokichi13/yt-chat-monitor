# yt-chat-monitor（YouTube配信コメント管理ツール）

YouTubeライブ配信のコメントを監視し、初見さんの検出やリスナー管理を行うブラウザツールです（スマホ表示前提）。

公開URL: https://misokichi13.github.io/yt-chat-monitor/

## 初回の設定
1. ページを開き、⚙️設定タブでYouTube APIキー（2本まで）を入力して保存
2. 同じ設定タブでGemini APIキーも保存（発話モニタリング機能を使う場合）
3. キーはファイルには書かれず、このブラウザのlocalStorageにだけ保存されます

## 主な機能
- 配信の自動検出（アップロード一覧からライブ枠を探します）
- コメントのリアルタイム表示と、初見さん・今日の初コメの判定とお知らせ
- リスナーの記録（読み方・メモ）をFirestoreに保存し、次回以降の来訪回数を表示
- 発話モニタリングによるコンディション判定

## 注意
- 配信中の主役はPS5のポップアップと読み上げで、このツールは「後から確認」と「チラ見」が役割です
- Firestoreのデータは、ログインした本人のアカウントに紐づきます
